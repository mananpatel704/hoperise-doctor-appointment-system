# HopeRise – Doctor Appointment Management System

HopeRise is a web-based Doctor Appointment Management System developed using PHP and MySQL.  
The system allows patients to register, view doctor information, and book appointments based on their requirements.

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- Bootstrap
- JavaScript

## Features
- Patient Registration
- Doctor Listing and Information
- Appointment Booking System
- Admin Management Panel
- Email Notification for Registration

## Project Structure
- Admin panel for managing doctors and appointments
- Patient interface for registration and appointment booking
- MySQL database for storing patient and doctor records

## How to Run the Project

1. Install XAMPP
2. Copy the project folder to:
   xampp/htdocs/
   
3. Import the database:
   hoperise_database.sql
   
4. Open browser and run:
(http://localhost/hoperise_medical/index.php)
